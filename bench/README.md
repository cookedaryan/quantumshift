# bench

C++17 PQC benchmark suite. Measures speed, sizes, memory and TLS handshake cost of post-quantum and classical algorithms with liboqs and OpenSSL 3.5, on a laptop and a Raspberry Pi. See [CLAUDE.md](CLAUDE.md) for module rules.
