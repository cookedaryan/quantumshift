# server/ (Java 21, Spring Boot 3, Maven)

Orchestrator, config and certificate parser, risk scoring, CBOM and the RAG planner.

- Orchestrator: runs each scan as a job, calls the scanner and classifier over gRPC, merges duplicate findings, pushes live progress over WebSocket.
- Config parser: nginx, Apache, SSH and Spring configs; certificates and keystores (.pem, .crt, .jks, .p12) with Bouncy Castle.
- Risk score combines four factors: vulnerability, data lifetime (Mosca: x + y > z means act now), exposure, and purpose. Priority runs P1 (fix first) to P4 (no action).
- CBOM output is CycloneDX 1.6 through cyclonedx-core-java; it must validate against the schema.
- RAG planner (Spring AI, PostgreSQL + pgvector): chunk NIST documents by section number; retrieve and rerank; benchmark numbers come from the database as a table and are never generated by the LLM.
- Guards: every number in a plan must match the benchmark table, and every citation must point to a passage that was actually retrieved. Anything that fails is flagged for a human. Test both guards.
- Generated plans are advice for engineers to review; nothing is applied automatically.
- Tests: `./mvnw verify`.
