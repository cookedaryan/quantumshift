# scanner

C++17 binary scanner. Finds cryptography in compiled programs by constant signatures, imported symbols and strings, using LIEF and YARA rules. See [CLAUDE.md](CLAUDE.md) for module rules and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for how it fits in.

Owner: role 1 (C++ binary scanner). Also builds the QuantumBank ATM firmware binary.

Status: not started.
